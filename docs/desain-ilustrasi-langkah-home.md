# Doodle 3 langkah di Home (#1748)

## Intinya
- Tiap langkah Home kosong kini punya doodle 48x48.
- Gaya sama dengan 7 aset lama: goresan tangan, stiker, stabilo.
- Sudah dipasang di app; teks tidak berubah.

## 1. Gaya
- Latar Biru Es, border Kertas ala stiker.
- Garis Plum Noir miring, aksen stabilo Wasabi.
- Tanpa maskot, tanpa teks, tanpa gradien.

## 2. Tempat pakai
- Home saat belum ada buku, daftar 3 langkah.
- Langkah 1: halaman + plus. Langkah 2: kata disorot + jari. Langkah 3: gelembung + gelombang.

## 3. Catatan
- Tiap file kurang dari 1 KB.
- Satu baris per langkah di 320px; teks mengecil sedikit di bawah 360px.
- Mockup: `docs/mockup-1748.html`.
