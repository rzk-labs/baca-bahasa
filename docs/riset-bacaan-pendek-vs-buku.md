# Riset: bacaan pendek vs buku utuh (#598)

## Intinya
- Pemula memang sering kewalahan di buku utuh. Bukti: kuat sebagai opini, bukan angka.
- Tidak ada data "tingkat selesai" pendek vs buku. Jawaban langsung: belum jelas.
- Usulan kecil: tunjukkan panjang bacaan dan ajak tempel lirik/artikel pendek.

## 3. Vonis hipotesis
1. Pemula kewalahan/menyerah di buku utuh awal — **terbukti sebagian**. Butir 6, 11, 13, 27, 31, 34. Tanpa angka putus.
2. Pemula lebih sering SELESAI bacaan pendek daripada buku — **belum jelas**. Tak ada data selesai. Butir 4, 26, 30 searah.
3. Lirik/artikel pendek memberi kemenangan cepat — **belum jelas**. Lirik bagus untuk kecepatan, lemah untuk paham (39).
4. Sesi 5-10 menit/satu bab cocok untuk KRL — **terbukti sebagian**. Butir 9, 30, 32. Tak ada data KRL.
5. Campuran pendek + panjang menjaga minat — **terbukti sebagian**. Butir 1, 3, 5, 35. Pendek saja tak cukup (butir 2, 33).
6. Tempel teks kurang dipakai karena orang tak tahu cari di mana — **belum jelas**. Tak ada data pemakaian; butir 12 (impor YouTube) menunjukkan orang cari sumber sendiri.

## 6. Usulan tugas kecil
1. Kartu buku: tampil "±N kata · ±M menit" (hitung dari teks).
2. Sheet "Tempel teks": petunjuk 1 baris, "Coba lirik lagu, artikel berita, atau satu bab".
3. Catat (lokal) berapa persen buku selesai per panjang; dasar bukti nyata saat beta.
