# Ilustrasi state kosong Kata & Ngomong (#1580)

## Intinya
- Ikon bulat generik diganti 3 doodle tangan-tulis.
- Satu coretan Wasabi per gambar = ciri khas Keepo.
- Sudah dipasang di app. Mockup: docs/mockup-1580.html.

## 1. Alasan gaya
- Selera Gen Z: buatan tangan, sedikit tak sempurna (referensi-visual.md).
- Warna datar, tanpa gradien, tanpa maskot.
- Latar blob Biru Es: gambar tetap jelas di tema gelap.

## 2. Tempat pakai
- Kata kosong: kartu + stabilo (`kosong-kata.svg`).
- Ngomong kosong: gelembung + garis suara (`kosong-ngomong.svg`).
- Lupa kosong: centang + bintang (`kosong-aman.svg`).

## 3. Catatan
- Mood 'cheer' (Latihan selesai) tidak diubah.
- Uji visual di 320px dan tema gelap tetap disarankan.
