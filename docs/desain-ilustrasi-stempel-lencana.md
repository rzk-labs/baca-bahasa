# Stempel lencana (#1841)

## Intinya
- Lencana terbuka di Profil kini punya stempel doodle, bukan ikon polos.
- Tiga stempel: kata, baca, streak. Terkunci tetap abu-abu.
- Sudah dipasang, tiap file sekitar 1 KB.

## 1. Alasan gaya
- Cap tinta bulat terasa seperti hadiah nyata.
- Wasabi hanya satu coretan per stempel.
- Latar Biru Es, jadi terbaca di tema gelap.

## 2. Tempat pakai
- Profil, kartu Lencana (cloud.js), ukuran 40px.
- Empat stempel baru: ngomong (gelembung), sempurna (target), boss (perisai retak), otak (kartu balik).
- Semua lencana terbuka kini bergaya stempel; yang terkunci tetap abu-abu.
