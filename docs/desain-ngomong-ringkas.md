# Layar Ngomong: buang yang "AI slop" (#1117)

Tugas founder: "Ai slope" + screenshot tab Ngomong. Dibaca sebagai: layar terasa generik, boros ruang, dan mic ketutup.

## Intinya
- Layar Ngomong penuh pengulangan: dua judul "tantangan" yang artinya sama.
- Kalimat bikin kartu tinggi (jarak baris 2.4), tombol mic jatuh di bawah menu.
- Usul: satu judul, kalimat rapat, mic kelihatan tanpa scroll di HP.

## 1. Masalah di screenshot
- "TANTANGAN HARI INI" lalu "Tantangan ngomong": pesan dobel, makan ±140px.
- Jarak baris kalimat 2.4: 5 baris makan ±400px.
- Mic sebagian tertutup menu bawah; harus scroll dulu.
- Logo "Ke" terpotong di header (sekitar header, dicatat terpisah).

## 2. Usul perubahan
- Buang tile "Tantangan hari ini" beserta ilustrasinya.
- Sisakan satu judul kecil: "Ngomong" + penghitung "Kalimat 73 dari 92".
- Jarak baris kalimat 1.6, ukuran huruf tetap 22-25px.
- Kalimat panjang (lebih dari 120 huruf): huruf 20px.
- Mic naik ke atas lipatan layar, ukuran tetap 96px.
- Tombol Contoh/Pelan tetap, di bawah kalimat.

## 3. Syarat selesai
- Layar 390x844: kalimat 5 baris + mic kelihatan penuh tanpa scroll.
- Layar 320px: mic minimal separuh kelihatan, tidak tertutup menu.
- Tap kata, skor ucapan, XP tidak berubah.
- Tema malam/gelap tetap terbaca.

## 4. Di luar tugas ini
- Teks contoh buku (soal "slop" isi buku): isi dari file pengguna sendiri, tidak diubah.
- Logo terpotong di header: tugas desain terpisah bila masih terjadi.
